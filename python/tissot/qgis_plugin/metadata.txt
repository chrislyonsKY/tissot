Analyze projection distortion with X-Ray heatmaps and Tissot ellipses, lint your data for cartographic and data quality issues, generate a 0–100 map quality score, visually diff two datasets, and auto-fix problems like suboptimal projections and topology gaps. All computation runs in a high-performance Rust core via the Tissot Python API. Requires the 'tissot' package installed in the same Python environment used by QGIS.
